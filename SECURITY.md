# Security Policy

Security fixes are provided for the latest release and the current `main` branch.

Please do not report vulnerabilities in public issues. Use [GitHub private
vulnerability reporting](https://github.com/yueqian-coder/multi/security/advisories/new).
If that channel is unavailable, open a minimal issue asking a maintainer to
establish private contact without disclosing vulnerability details.

Include a concise description, affected version or commit, reproduction steps using synthetic data, and impact. Do not include live credentials or sensitive personal data.
